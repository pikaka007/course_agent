# 第五版 本地学习事务与技能扩展

CourseMate 围绕课程学习增加本地日历、学习计划、邮件草稿和复习自测。用户明确排除了“从文档提取作业与截止时间”，因此任务和日期由用户提供。本轮按用户选择使用本地日历与草稿，没有连接在线账户，没有邮件发送功能。

## 已实现

| 功能 | 实际行为 |
| --- | --- |
| 技能管理 | 动态注册标准 Function Calling 工具；安装、查看源码、启停、依赖检查、内容指纹与执行状态 |
| 手动任务 | 用户填写标题、预计分钟、优先级、可选完成时间；编辑与进度变更先预览 |
| 本地日历 | ICS 导入预览、逐条确认、查询已有事件、调整事件时间；提交时重新检查冲突 |
| 学习计划 | 根据任务时长、优先级、用户指定时间窗与已有日历寻找连续空档；无空档则明确报告 |
| 邮件草稿 | 按给定收件人和用途起草，预览、确认保存、编辑副本、下载 .eml；不发送 |
| 复习自测 | 基于本轮读取的原文生成题目与参考答案；确认后作答、查看原文、自评和1/3/7天复习日期 |
| 提醒 | 打开或刷新学习事务时显示临近安排、任务到期与复习到期；不是后台推送 |
| 交互终端 | 延续多轮聊天、流式输出、会话恢复；新增技能列表、安装启停、学习事务、确认拒绝、ICS预览、草稿导出 |

模型只能提出写入预览。确认由网页按钮或终端命令完成；同一提案重复确认不会重复写入。发生冲突时保留待确认提案，便于拒绝后重新规划。

## 架构与作业对应

模型 → 标准 Function Calling → 动态工具注册 → 本地文档 / SQLite / Python 插件 → 工具结果回传 → 引用核对 → 回答。

原有资料列表、检索、读取、笔记保存四个工具保留；另有八个内置技能包。下载的第三方插件须符合本项目 `skill.json + handler.py` 协议，不能宣称任意 SKILL.md 或 MCP Server 都能直接运行。本版未实现 MCP Server，也未引入 Pydantic；采用 JSON Schema 和运行时参数校验，满足作业允许的标准 function calling 路径。API 请求逻辑、工具 Schema 和编排代码均由 Codex 编写。

## 数据与权限

`local/study.sqlite3` 保存任务、日历、草稿、自测、自评及确认记录；`local/skills.json` 保存启停状态、指纹和最近执行状态；`local/skills/` 保存安装代码；终端导出的邮件位于 `local/exports/`。这些路径均由 `/local/` 排除在 Git 外。浏览器下载的邮件保存在浏览器指定目录。

`data/`、`outputs/`、`logs/`、`evidence/` 延续忽略策略，只有说明或占位文件例外。源码 ZIP 使用白名单，排除本机数据、密钥、运行证据和 Git 历史。Git 忽略规则不能清除以前已经提交的历史内容。

Python 插件不是安全沙箱：它拥有运行用户的本机权限。安装默认停用，查看代码并信任后启用；修改包内容会自动停用。环境变量过滤、20秒超时和输出长度检查只是运行约束，不能防止恶意代码读文件或联网。不要启用不可信代码。

本机保存不等于完全离线处理：真实模型模式会把相关资料及工具返回的学习事务内容发送给配置的模型平台。不要导入不希望用于该模型处理的私人日历或邮件。

## 已知范围

- ICS 支持 UTC、Asia/Shanghai 与未带时区的本地时间，要求明确开始和结束。重复事件必须先展开；其他时区拒绝导入，不静默猜测。
- 计划采用15分钟步长寻找连续时段，不是最优排程器，不会自动拆分长任务。已有安排的任务不会重复排期。
- 自测参考答案由模型生成，需用户核对原文；自评是用户评价，不是客观评分。
- 证据审核为模型辅助检查，允许忠实翻译和转述，但验证引用摘录必须确为连续原文。仍可能误拒绝或遗漏错误。
- 同机多进程适合共享读取；技能管理不建议在网页与终端同时修改。

## 验证

离线回归见 `evidence/v5/test-results.txt`；真实模型回执见 `evidence/v5/live/`，初次失败也保留。`summary.json` 是初次四场景记录，`summary-quiz.json` 是自测场景最近复测，不能将初次失败从历史中抹掉。真实验收仅使用自编小文档、示例邮箱与临时学习数据库。

复现：`python -m unittest discover -s tests -v`。显式真实验收：`python scripts/live_study_acceptance.py --live`，会产生 API 用量；可加 `--case quiz` 单独复测。具体安装格式见 `docs/skill-authoring.md`。
