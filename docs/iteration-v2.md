# 第二版迭代记录

本轮按用户要求继续完善本地项目，未发布或更改远程仓库。

## 已完成的变化

1. 检索支持 RAG、MCP、Tool Use、提示注入、实验一等中英文短词映射；英文按词边界匹配，避免 Shor 命中 shortcuts。全部查询词仍须出现，不丢弃额外约束；README 等说明文件不参与课程证据。
2. 新增来源校验和段落覆盖提示。一个正确引用不能掩盖其他伪造引用；最终回答自动修正最多两次，仍有未知或缺失引用则失败。保存笔记还要求长内容行有就近引用。
3. 解析结果按路径、修改时间、大小缓存；上限 16 项，每项至多 25 万文本字符。更大文档不缓存。一次运行内相同的只读工具参数可复用结果，save_note 从不复用。提示词减少无关阅读。
4. 后台任务提供真实阶段事件；前端每约 0.8 秒查询进度，刷新可恢复任务查看。新增原文展开、笔记预览与下载。下载严格限制在 outputs 目录。
5. 新增检索、缓存、引用修正和 HTTP 集成测试，共 33 项通过。

## 校验边界与本次实际发现

第二版首轮生成的笔记虽然引用来源真实，但把五项步骤的标题写成了“六步”，并把课件里的 studio 拼写直接用作术语。这说明来源格式正确并不能证明内容正确。已补充标题数量核对、仅回答所问主题和疑似课件拼写的提示，再次生成 `mcp-study-note-v2-verified.md`；复验笔记的五步标题与五个列表项一致，没有扩展传输层。

保留首轮与复验原始日志，未修改模型原始输出来美化结果。复验仍不构成自动语义事实核查；尤其 PPTX 只抽取文字，不能仅凭它确认图形箭头或图片语义。读者仍应对照原课件。

Windows 下载测试最初将文件 CRLF 与 LF 文本直接比较导致失败，修正测试为下载内容与磁盘原始字节比较，从而验证真实的“不改写笔记内容”要求。

证据位于 `evidence/v2/`，自动化输出为 `evidence/test-results-v2.txt`。第一版证据继续保留用于对照，界面查看历史记录时会提示尚未执行新版引用检查。
