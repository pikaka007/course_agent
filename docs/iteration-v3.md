# 第三版迭代记录

触发问题：用户指出运行数据可能公开、网页过于简单且静态、官方平台没有调用，以及希望 CLI 像 Codex 一样可持续交互。

实际修改：修正配置优先级，切到用户确认的官方接口和官方模型别名；记录接口与模型回执。引入 frontend-design 技能，重做阅读工作台，并加入资料上传/范围选择/回收站、可编辑模板和回答偏好。新增 Rich 与 prompt-toolkit 终端，支持会话恢复、补全、工具进度和斜杠命令。前后端统一 Agent 核心，历史只作为追问上下文，每轮重新取证。

测试与实际官方调用见 verification.md。兼容网关的旧证据保留并标注，不能篡改成官方账号的记录。用户身份信息继续留空。
