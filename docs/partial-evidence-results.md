# 证据核对的部分结果处理

文档总结中，个别表述审核失败不再直接丢弃整份回答。

1. 第一次审核失败时，在剩余轮次允许的情况下尝试一次修正。要求保留已通过内容，只修正或删除未通过段落。
2. 修正仍有问题时，从有效审核结果中提取已经通过且附有校验摘录的完整段落。剔除未通过段落以及可能不再成立的原标题和编号，不自动拼接、改写未经核对的事实。
3. 页面标记“部分内容通过核对”，回答说明省略了多少段落；证据核对视图保留原草稿全部审核结果，明确哪些没有进入最终答案。
4. 修正后变得更差时，保留之前有效审核中已通过的内容。到达最后一轮也可以返回已核对部分，不再无条件进入下一轮而丢失结果。
5. 没有任何可信段落、引用不合法或审核服务结果无效且没有此前已核对内容时，仍不输出未经验证的草稿；错误提示区分审核故障与内容未通过。
