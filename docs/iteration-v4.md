# 第四版迭代与验收

2026-10-29。本版围绕检索、证据可信度和持续使用体验迭代，仍使用标准 LLM Function Calling，未实现 MCP Server。网页、交互终端与单次脚本共用 Agent。

## 已实现

- SQLite FTS5 全文索引、BM25 候选排序、短语和中文双字匹配、内嵌术语扩展；文件修改后更新索引。属于词法检索，没有使用向量模型，不能保证理解所有同义改写。
- 引用格式检查后，再由模型逐段判断引用是否支持结论；程序检查审核覆盖和逐字连续摘录。不通过时修正一次；仍失败则明确报错。笔记写入前也核对。资料不足可走固定拒答出口。
- SSE 流式模型响应，先完整组装工具参数再执行。网页轮询的是累积草稿，不会因事件队列裁剪丢字；草稿明确标注未核对。终端 Rich 实时显示草稿和工具进度。
- Ctrl+C / 停止可在接收流时及时结束前台等待。底层阻塞读取由后台线程收尾，最迟受接口读取超时约束；DNS、连接及响应头阶段仍可能等待最多配置的超时。取消不保证服务端停止计费，也不回滚已保存文件。
- 文字型 PDF，保留真实页码，空白页不重新编号；读空白页时返回可读区段。扫描件需另做 OCR；不支持加密 PDF。40 MB / 500 页 / 单页 24000 字 / 总计 200 万字 / 解析子进程 30 秒限制。不是隔离任意恶意 PDF 的安全沙箱。
- 网页可点击回答中的引用查看并排原文；逐段核对视图、会话搜索、完整 JSON 导出、单会话删除、过期会话预览与确认清理、编辑问题到新会话。
- 终端支持带描述的命令菜单、无参数 /resume 的编号选择、/sessions 关键词、/retry、/edit、/export、/review；/trace 需要时展开完整工具轨迹。不是任意 Shell 代理。
- SQLite 会话事务，旧 local/sessions JSON 首次自动导入且原文件保留；界面加载最近 100 轮，SQLite 保留完整历史，导出/删除覆盖完整历史。模型仅使用最近 6 轮成功且同模式的对话。

## 数据位置

| 路径 | 内容 | Git 默认 |
| --- | --- | --- |
| .env | 本机模型接口、名称、密钥 | 忽略 |
| data/ | 用户导入资料 | 忽略，README 除外 |
| outputs/ | Markdown 笔记 | 忽略 |
| logs/ | 问答、工具结果、原文、请求回执 | 忽略 |
| local/workspace.sqlite3 | 持久会话 | 忽略 |
| local/index.sqlite3 | 全文及检索索引，含原文副本 | 忽略 |
| local/settings.json | 回答偏好与模板 | 忽略 |
| local/trash、history-archive、exports | 回收站、归档、会话导出 | 忽略 |
| evidence/ | 本机实验截图与日志副本 | 忽略，README 除外 |

SQLite 可能产生 -wal/-shm 旁文件，也都在被忽略的 local/ 内。索引可在服务和终端关闭后删除，下次检索重建。删除会话会删除它的已存轮次及关联日志/旧 JSON 副本，保留资料、笔记、独立运行日志和 evidence 副本；不承诺取证级擦除。保留天数仅用于手动预览，不会后台自动清理。备份数据库前关闭应用，或完整备份 local/ 及资料、笔记。

## 可复现验证

运行 `python -m unittest discover -s tests -v`，本轮 71 项通过，完整输出在 evidence/v4/test-results.txt。测试使用临时目录、替身模型及本机 HTTP，含截断 SSE、分片参数、跨片段密钥脱敏、取消阻塞读取、PDF 页码/空白/加密、索引失效与范围、审核错误摘录、会话并发/迁移/删除/过期预览。不会将自动化测试误写成真实模型验收。

`scripts/evaluate_retrieval.py` 含自编语料和 16 条固定问题：12 条有答案、4 条无答案。V3 Hit@3 和 MRR@3 为 0.3333，V4 为 1.0；两版负例正确率均为 1.0。该集合偏向项目常见概念与问法，只用于回归，不能推断一般准确率。索引创建和缓存影响耗时，不作公平速度比较。完整逐题结果在 evidence/v4/retrieval-evaluation.json。

## 限制

证据核对使用同一模型，不是独立事实核查，可能误判且增加用量与等待。扫描件、复杂版式图表、公式语义未覆盖。检索仅限 100 份资料和前 300 个候选片段。编辑重试创建新会话，不复制旧上下文。每个进程只调度一个网页任务；SQLite 避免会话文件写坏，但两个客户端同时对同一会话提问仍可能使用不同上下文快照，建议等一轮结束再切换。

参考实现依据：[DeepSeek 流式接口](https://api-docs.deepseek.com/api/create-chat-completion/)、[SQLite FTS5](https://www.sqlite.org/fts5.html)、[pypdf 文本提取](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)。
