# 工作台设计说明
使用 frontend-design 技能（anthropics/skills）进行两阶段设计与审查。

用户是研究生，核心任务是带着问题阅读课程资料、核对原文、保存笔记。采用安静的蓝灰阅读工作台：墨蓝 #243858、操作蓝 #3559B9、纸白 #FFFFFF、背景 #F6F8FC、分隔 #DFE5EF、正文 #203044。中文使用系统等线/微软雅黑，标题略提高字重；代码才用 Consolas。正文左对齐、限制阅读宽度，来源不夹杂在主回答里。

布局：左侧会话导航 | 中央阅读与输入。资料和设置作为独立工作区，避免把所有内容挤在问答侧栏。引用与工具明细是可展开的证据抽屉。移动端导航折为顶部控件，表单单列。

初稿曾考虑三栏常驻引用栏，审查后改为按需展开：课件名称较长，三栏会挤压中文阅读宽度。拒绝无意义的指标卡和宣传式首页；空会话直接呈现资料状态、可编辑任务模板和输入框。

交互原则：键盘焦点可见；错误提示给出恢复路径；上传和保存显示真实结果；运行中锁定配置修改但允许请求停止；演示模式始终显式标记；HTML 全部通过文本节点渲染模型/资料内容，不执行其中的 HTML。
