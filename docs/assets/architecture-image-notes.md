# 架构图制作说明

图片：`agent-architecture.png`。使用内置 imagegen 工具生成，并根据代码核对和修正标签。该工具没有暴露可选择的模型版本参数，因此不将具体模型版本写作已验证事实。

生成提示词：绘制 CourseMate 中文架构图，白底、深蓝与青绿色。Web 学习工作台和 CLI 交互终端进入共享 Agent 编排层，展示系统提示词与会话上下文、工具选择、JSON 参数校验、执行与回传、有界循环和异常处理。DeepSeek API 通过标准 Function Calling 与编排层双向通信。下方展示资料工具、学习工具和扩展技能，以及课程文件、SQLite FTS5 索引和本地学习数据库。学习事务写入必须经过提案和用户确认。回答流程展示原文证据、引用校验、语义核对和完整或部分回答。不绘制 MCP Server、向量数据库或发送邮件功能。

修正提示词：保留整体布局，将索引说明改为“课程资料文件 · FTS5 全文检索”，CLI 说明改为“多轮对话 · 斜杠命令 · 工具过程”，学习数据库说明改为“任务 · 日历 · 草稿 · 复习记录”。将学习工具到数据库的箭头标为“读取上下文”，增加确认提案到数据库的“确认后写入”箭头。

图中写入确认针对学习事务；Markdown 笔记写入由独立的保存权限控制。技能自身的权限边界见技能开发指南。
