# 引用失败恢复与文档目标选择

此前的修复仅覆盖语义证据审核，未覆盖它前面的引用校验。新版本统一处理这两阶段，保留真实失败诊断，避免将局部问题直接变成整次失败。

## 明确总结哪份文档

当前范围包含多份 PPT，而用户只说“总结一下这个ppt”时，先根据本地文件列表询问目标。网页提供文件按钮，点击后将本轮范围限定到该文件再发送原问题；询问过程不调用模型。用户已经选定一份文件、明确文件名，或明确要求分别总结多份时，不重复询问。新上传的文件自动成为当前资料范围。

这是有限的意图规则，覆盖常见中文总结请求，不承诺理解所有指代。页面上的资料范围仍是决定本轮可访问文件的依据。

## 两阶段恢复

1. 完整引用与已知来源仅有空白或中括号样式差异，且唯一匹配时，程序直接修正排版。不会猜测文件名、补造页码或给无来源句子随意分配引用。
2. 模型最多修正引用两次，有剩余轮次才重试。仍有局部问题时，只保留引用完整、属于本轮来源的整段文字，再进入语义证据审核。带未知引用或没有引用的内容不自动放行。
3. 语义审核继续校验原文摘录。通过的部分可以输出，但必须标为“部分内容通过核对”；失败内容不会伪装为完整总结。
4. 已经通过语义核对的部分，在后续修正引入新的引用错误时仍保留，不因阶段切换而丢弃。
5. 如果完全没有可验证内容，仍明确拒绝输出草稿，并保留具体诊断。这不等于文件读取失败，也不再笼统要求用户缩小问题。
